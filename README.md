# 机器人与安全实验操作指南

**[打开实验指导网站](https://weihangzhu4321.github.io/robotics-safety-lab-guide/)**

第一次做实验，打开网站后点「从实验零开始」。已经配好环境，点「查看实验目录」，选实验一至十一。网站可直接阅读，无需登录 GitHub。

实验零有 VMware 打开虚拟机、设置密码和桥接网卡的步骤。Ubuntu 虚拟机和实验文件随课程资料分发。

- [网页源码](docs/)：首页、实验零至十一的 HTML，以及配套样式、脚本和图片。
- [实验源码与环境重建说明](lab-files/)：按实验编号整理的脚本、配置示例、仿真文件和依赖校验清单。
